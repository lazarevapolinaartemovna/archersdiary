# 🏹 Дневник лучника

Простой сайт-дневник лучника: минимум элементов, всё в одном файле `index.html`.

## Разделы (страницы)

- **Лэндинг** — название, короткое описание, кнопки «Начать» и «Войти».
- **Регистрация / вход** — имя и пароль, режимы переключаются одной ссылкой.
- **Ввод результатов стрельбы** — поля как в Google-форме: дата тренировки, дистанция (м), количество выстрелов, количество попаданий, набранные очки, средний балл (считается автоматически), систематическая ошибка. Плюс интерактивная мишень: клик по зоне добавляет стрелу в серию и сам считает выстрелы, сумму очков и средний балл (есть «Отменить стрелу» и «Сбросить серию»). Под полем очков выводится «Набрано очков: X из N возможных (процент)», а под средним баллом — ориентировочное соответствие спортивному разряду (3-й, 2-й, 1-й, КМС) по проценту от максимума с учётом дистанции; пороги заданы в коде (массив `RANK_STEPS`) и приближены к ЕВСК — при желании замените на официальные нормы.
- **График прогресса** — линия очков по тренировкам + фильтр по дистанции и средний результат.
- **Журнал** — таблица всех тренировок со всеми полями, удаление в два клика (✕ → «Удалить?»).

## Посмотреть локально

Просто откройте `index.html` в браузере двойным кликом.

## Как опубликовать на Тильде

### Способ 1 — блок «HTML-код» (T123)

1. Откройте `index.html` в любом текстовом редакторе (подойдёт Блокнот).
2. Скопируйте всё, что находится между строками
   `ДНЕВНИК ЛУЧНИКА · НАЧАЛО` и `ДНЕВНИК ЛУЧНИКА · КОНЕЦ` (включая `<style>`, `<div id="archer-app">` и `<script>`).
3. В Тильде: нужная страница → **Добавить блок** → раздел **Другое** → блок **T123 «HTML-код»** → вставьте код.
4. В настройках блока включите «Растянуть на всю ширину» (по желанию) и опубликуйте страницу.

### Способ 2 — через iframe (отдельная страница без оформления Тильды)

1. В Тильде: **Настройки сайта → Файлы** → загрузите `index.html` → скопируйте прямую ссылку на файл.
2. Добавьте на страницу блок T123 и вставьте:

```html
<iframe src="ССЫЛКА_НА_ФАЙЛ" style="width:100%;height:860px;border:0"></iframe>
```

## Где хранятся данные

Аккаунты и записи хранятся в **localStorage браузера** — сервер не нужен, поэтому публикация на Тильде бесплатна и работает сразу.

## Фон страниц

Фон — векторные мишени, встроенные прямо в файл: работают без интернета и ничего не подгружают. На лэндинге — тёмная мишень со стрелой, на остальных страницах — едва заметные светлые мишени-подложка.

Чтобы поставить фотографию вместо векторного фона:

1. Скачайте фото (например, с Unsplash — бесплатно, без указания автора) и загрузите его в Тильде: **Настройки сайта → Файлы**. Скопируйте прямую ссылку на файл.
2. В `index.html` найдите строку `--heroimg:url(...)` (фон лэндинга) или `--bgimg:url(...)` (фон остальных страниц) и замените содержимое на `url("ваша-ссылка")`.

Подходящие фото из поиска (открываются с обычного интернета):

- [Лучник целится в мишень, тёмный фон](https://unsplash.com/photos/selective-focus-photography-of-arrow-target-3qbBwA8QCEY) — хорош для лэндинга
- [Стрелы в яблочке, крупный план](https://unsplash.com/photos/archery-targets-with-arrows-in-the-bullseye-DXGtmrGmmJI) — хорош для светлой подложки
- [Мишени на деревянном стенде](https://unsplash.com/photos/archery-targets-lined-up-on-a-wooden-wall-rVCi01yIOSs)
- [Лучник с луком, вид со спины](https://unsplash.com/photos/white-and-brown-composite-bow-jY9mXvA15W0)

Ограничения этого подхода:

- дневник привязан к конкретному браузеру на конкретном устройстве (между телефоном и компьютером данные не синхронизируются);
- очистка данных сайта в браузере удалит записи.

Если понадобится настоящий аккаунт с синхронизацией между устройствами, к форме можно подключить бесплатный Firebase — структура кода это позволяет.
